# Chat, Personality, and Roleplay

PETEY supports multiple saved conversations. Use separate chats for projects,
characters, campaigns, worlds, or storylines.

## Personality

Open **Settings → Personality & voice** to change PETEY's name, role, tagline,
behavior, speaking style, and system instructions. Five persona slots can preserve
a complete personality and voice setup.

Personas work well for:

- Original characters and companions
- Game masters and interactive fiction
- Narrators and collaborative writing partners
- Focused assistants for different kinds of work

Add lore, character sheets, campaign notes, or world documents in **Knowledge** so
PETEY can retrieve relevant details while responding.

## Attachments and vision

Attach an image in Chat and ask PETEY to inspect or discuss it. Image inspection
uses Gemini even when the selected chat provider is OpenAI or local. See
[API Keys and Providers](API-Keys-and-Providers) for that configuration.

## Temporary conversations

Turn on **Temporary** before sending a message when that conversation should not
read or write PETEY's stored memory. The current temporary history remains in the
open window so the conversation can continue.

Temporary mode can still contact configured providers, inspect attachments, invoke
tools, and generate media. It is a memory setting, not an offline mode.

## Visual mode

Visual mode replaces the standard transcript with an audio-reactive presentation.
Choose an animation style and use F11 for fullscreen. Progressive captions appear
while PETEY speaks.
