Web browser

Watch Petey browse in a separate window.

Off

If automatic search cannot read results, Petey reports the block. You can handle a site's challenge yourself in the browser window; protected sites may still require manual access.

The window opens on the computer running PETEY, including when you chat from your phone. Browser cookies and sign-ins stay in a separate local PETEY profile. Enter passwords yourself in that window. Switching access off closes it immediately after any running action finishes.

Chromium, Chrome, or Edge is required. If Open browser cannot find one, use Install Chromium. This downloads the browser once.

MCP servers

Connect Petey directly to local or remote MCP servers. No add-on required.

Import server configuration

Paste the server's mcpServers JSON. Local servers use command, args, and optional env/cwd; remote servers use a Streamable HTTP url and optional headers. Importing leaves every server off. Test connection starts the local command or contacts the endpoint. Only import servers you trust.

Memory stays managed by Petey locally. Server credentials are stored locally and hidden from this page after import. Reimport a server with the same name to change its command or credentials.
