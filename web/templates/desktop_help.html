GETTING STARTED

Help

Make yourself at home with PETEY.

Your first conversation

Start with one chat provider. Add voice, media, and memory search when you want them.

  1. Get a key. Choose Gemini or OpenAI below, or use an already running local model server.
  2. Save it in PETEY. Open , paste it into the matching provider field, and select Save key.
  3. Choose a model. In , choose the provider and a model, then Save provider and Test connection. Testing sends a small request to the provider.
  4. Say hello. Open Chat and send a message. Enter sends; Shift+Enter adds a new line.

Get your API keys

An API key connects PETEY to your account with a provider. You only need keys for the services you use. Keep keys in Settings, never in a chat message.

Google Gemini

Chat and image understanding, with optional spoken replies, transcription, and memory search.

Sign in to Google AI Studio. Create or copy a key on the API keys page, then save it in PETEY’s Google Gemini field.

Get a Gemini key ↗ Google’s key setup guide ↗

OpenAI

Chat, with optional spoken replies and memory search.

Sign in to the OpenAI Platform and create an API key for your project. Save it in PETEY’s OpenAI field and check your API billing and usage limits.

Get an OpenAI key ↗ OpenAI’s setup guide ↗

deAPI

Images, video, music, and speech in Media, plus microphone transcription.

Sign in to deAPI, open Dashboard → Settings → API Keys, and create a new secret key. Save it in PETEY’s deAPI field and check your credit balance.

Open deAPI dashboard ↗ deAPI’s setup guide ↗

Provider usage can cost money. Check the provider’s current pricing, balance, and limits before generating. A model appearing in the list does not guarantee your account can use it.

Make PETEY yours

Personality and spoken replies

Set PETEY’s character and tone in . Choose a speech service in , then pick his voice and whether to speak replies automatically. Chat and speech use separate settings.

Using your microphone

Open to choose an input device and listening mode. Allow microphone access when prompted. Transcription uses deAPI with Gemini fallback, or Gemini directly, according to your provider settings.

Creating images, video, and music

Save your deAPI key, then open . Choose an operation and model, add a prompt and any required input, and review the estimate when available. Jobs can take time; watch their progress and find completed creations in Gallery.

Local models and image attachments

Start your local model server and load a chat model. In , choose Local, enter its OpenAI-compatible server URL, select a model, and save. Image attachments still use Gemini for descriptions, so they need a Gemini key even with local or OpenAI chat.

Memory, knowledge, and temporary chats

Saved conversations and generated media live in PETEY’s application-data folder. Add reference files in and configure a separate embedding model under . Hosted providers receive relevant text or attachments needed for the feature you use.

Turn on Temporary in Chat to skip saved memory reads and writes for that conversation. Temporary chats can still contact providers and generate media; temporary does not mean offline. Manage stored chats in .

Working with folders

Approve a folder in before browsing or editing it. Review proposed changes and commands before approving them. Optional filesystem tools are enabled in Settings → Tools and can read only approved folders.

If something isn’t working

  • Chat fails: confirm the key is saved for the selected provider, save your model choice, then use Test connection. Check the provider’s error message, account access, quota, and balance.
  • No voice or microphone: check the separate speech and transcription providers, their keys, your selected device, system volume, and microphone permissions.
  • Shortcut stopped opening after a move: from the new project folder, activate its Python environment and run python run_desktop.py --install-shortcut on Linux. Close and reopen PETEY after updating.
