GETTING STARTED

Help

Make yourself at home with PETEY.

Your first conversation

PETEY is local-first: the app, conversations, profiles, memory, knowledge, and gallery live on this computer. Start with a local chat server when you want model requests to stay on your machine, or connect a hosted provider.

  1. Choose where chat runs. Start LM Studio, Ollama, or another OpenAI-compatible server for local chat, or choose Gemini or OpenAI.
  2. Choose a model. In , choose the provider and model, then select Save provider and Test connection.
  3. Add a key only when needed. Hosted providers use keys saved under . Local chat does not require a cloud key.
  4. Say hello. Open Chat and send a message. Enter sends; Shift+Enter adds a new line.

Choose local or hosted AI

Each capability has its own route. Use local options where available, then add hosted-service keys only for the features you choose. Keep keys in Settings, never in a chat message.

Local on this computer

LM Studio, Ollama, and compatible servers can power chat, prompt enhancement, and memory embeddings. Local Whisper can transcribe microphone recordings privately.

Image attachments use the active chat model; choose a vision-capable local model to keep them local. Spoken replies currently use deAPI, Gemini, OpenAI, or Fish Audio text-to-speech and can remain disabled.

Fish Audio

Optional spoken replies using a Fish Audio voice model ID.

Save your key in Fish Audio speech under Models & API keys, then choose Fish Audio and paste the voice model ID under Personality & voice.

deAPI

Images, video, music, and speech in Media, plus microphone transcription.

Sign in to deAPI, open Dashboard → Settings → API Keys, and create a new secret key. Save it in PETEY’s deAPI field and check your credit balance.

Open deAPI dashboard ↗ deAPI’s setup guide ↗

Provider usage can cost money. Check the provider’s current pricing, balance, and limits before generating. A model appearing in the list does not guarantee your account can use it.

Make PETEY yours

Personality and spoken replies

Set PETEY’s character and tone in . Prompt improvement follows the selected chat provider, including a local model. Spoken replies are separate and optional; choose deAPI, Gemini, OpenAI, Fish Audio, or Disabled, then pick a voice and whether to speak automatically. Fish Audio uses a voice model ID copied from its website and a separate key in Models & API keys.

Using your microphone

Open to choose an input device and listening mode. Push to talk adds a large microphone control to fullscreen Visual mode. Trusted phone access launched with python run_desktop.py --lan-https supports live hold-to-talk without the keyboard; plain HTTP offers keyboard dictation instead. Live microphone transcription can use automatic deAPI-to-Gemini fallback, either hosted provider by itself, fully private Local Whisper on the PETEY computer, or a dedicated OpenAI-compatible transcription server.

Creating images, video, and music

Save your deAPI key, then open . Choose an operation and model, add a prompt and any required input, and review the estimate when available. Jobs can take time; watch their progress and find completed creations in Gallery.

Creating and editing images in Chat

With a deAPI key and a chat model that supports tools, turn on Allow Petey to control for deAPI Media in Add-ons. Then ask PETEY to generate an image. To edit or combine images, use the plus button to attach them to the same message and describe the changes. You can refer to Image 1, Image 2, and so on. Finished images appear in Chat and Gallery.

Local models and image attachments

Start your local model server and load a chat model. In , choose Local, enter its OpenAI-compatible server URL, select a model, and save. Chat and prompt enhancement then use that local model. Image attachments also stay on that route when the selected model supports vision; otherwise PETEY reports that the model cannot inspect the image instead of silently sending it elsewhere.

Memory, knowledge, and temporary chats

Saved conversations and generated media live in PETEY’s application-data folder. Add reference files in and configure a separate embedding model under . Hosted providers receive relevant text or attachments needed for the feature you use.

Turn on Temporary in Chat to skip saved memory reads and writes for that conversation. Temporary chats can still contact providers and generate media; temporary does not mean offline. Manage stored chats in .

Letting Petey read folders

Open to choose folders for the optional Filesystem connector. Petey receives read-only file tools scoped to those folders; write, move, delete, and command tools are not available.

Connecting PETEY to Discord

Open and follow the numbered setup. Create an official bot in Discord's Developer Portal, enable Message Content Intent, save its bot token in PETEY, add it to a server, then choose a text channel. PETEY keeps a Discord Gateway connection open so the bot appears online. Auto-connect can rejoin the last successful server and channel when PETEY starts. Spontaneous participation defaults to Auto while direct messages and conversational follow-ups receive priority. Edit the Room prompt to change Discord-specific behavior; AI enhance can revise the draft, and saved changes apply on the next reply. Media commands such as /genimg and /img2img use PETEY Desktop's deAPI key, selected models, queue, and Gallery while the app is connected. Owner requests to create or delete the selected channel or clear recent messages become reviewable proposals; public channel messages cannot request server actions. Normal user-account automation is not supported.

Installing and managing add-ons

Open to see installed modules, open the local add-ons folder, and choose what PETEY loads. Add-ons run local Python code with PETEY's permissions, so install only modules you trust. Enabling or disabling one takes effect after PETEY restarts. PETEY bundles only Discord; external add-ons are installed separately. Developers can use docs/addons.md as the authoring contract.

If something isn’t working

  • Chat fails: confirm the key is saved for the selected provider, save your model choice, then use Test connection. Check the provider’s error message, account access, quota, and balance.
  • No voice or microphone: check the separate speech and transcription providers, their keys or Local Whisper setup, your selected device, system volume, and microphone permissions. On a phone, open PETEY in Safari or Chrome itself and allow microphone access both for the PETEY site and for the browser app.
  • Shortcut stopped opening after a move: from the new project folder, activate its Python environment and run python run_desktop.py --install-shortcut on Linux. Close and reopen PETEY after updating.

For installation and update instructions, see the project README ↗. Report a problem on GitHub ↗ with PETEY’s version (v{{ app_version }}), your operating system, and the error message. Leave API keys and private chats out of reports.
